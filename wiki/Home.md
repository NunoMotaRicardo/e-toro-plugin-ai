# e-toro-plugin-ai

An AI plugin that lets coding and chat agents work with the [eToro Public API](https://api-portal.etoro.com/): market data, portfolio, watchlists, feeds, popular investors and trading. Demo-first by design. Distributed via the [nmr-plugins](https://github.com/NunoMotaRicardo/nmr-plugins) marketplace.
